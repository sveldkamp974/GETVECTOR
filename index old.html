JPEG vs Vector

A JPG or PNG is built from pixels. Zoom in far enough and it turns blocky. Printers, embroiderers and sign makers need a vector file instead, built from lines and shapes, so it stays sharp at any size. Renaming a JPG to ".eps" doesn't change that.
